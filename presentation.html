Problem Statement
Fragmented data sources and lack of real-time strategic intelligence
The Data Fragmentation Challenge
Modern cricket generates massive volumes of detailed data, but it exists in isolated silos across multiple disparate formats:
  • Player Statistics: Historical records for batting averages, strike rates, and bowling economies.
  • Venue & Weather Conditions: Pitch pace, spin ratings, humidity, temperature, and dew factors.
  • Ball-by-Ball Feeds: Detailed event logs capturing runs, boundaries, and wickets.
  • Squad Dynamics: Team composition changes and role assignments across phases.
Consequence: Current match analysis is manual, partial, and performed too late during a tournament to influence real-time strategy.
Required Platform Deliverables
  • Data Source Simulation: Generate T20 match feeds for 20 international teams across 10 venues using Python.
  • Data Warehouse Design: Architect a clean SQLite relational database schema stitching player stats, matches, and weather.
  • Automated ETL Pipeline: Automate data extraction, cleaning, transformation, and feature storage using Pandas.
  • ML Win Predictor: Train Random Forest and Logistic Regression models for probabilistic match outcome predictions.
  • GenAI Strategy Layer: Automatically synthesize model outputs into actionable tactical briefs for team management.
  • Streamlit Dashboard: Interactive web interface for team analysis, live predictions, and strategy exports.

Machine Learning Predictive Engine
Feature engineering, model training, and accuracy benchmarks
Predictive Pipeline Steps
  • 1. Data Preparation: Extract 17 match metrics including ranking differentials, 2-year win rate delta, pitch spin ratings, and dew factors using Pandas.
  • 2. Encoding & Cleaning: Encode categorical pitch and toss attributes using Scikit-Learn LabelEncoder; fill missing data using median values.
  • 3. Cross-Validation: Evaluate models using Stratified 5-Fold Cross-Validation to ensure unbiased performance.
  • 4. Model Fitting: Fit Random Forest (200 decision trees) and Logistic Regression classifiers.
  • 5. Model Output: Generate win probability percentages %, model confidence scores, and top predictive drivers.
